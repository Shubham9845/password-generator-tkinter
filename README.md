# 🔐 Password Generator (GUI)

A desktop-based password generator built using **Python Tkinter** that creates strong and random passwords.

## 🚀 Features
- Generate secure random passwords
- Supports customizable password length
- Uses letters, digits, and special characters
- Simple and user-friendly GUI

## 🛠️ Technologies Used
- Python
- Tkinter (GUI)

## ▶️ How to Run
1. Install Python
2. Clone the repository:
   git clone https://github.com/Shubham9845/password-generator-tkinter.git

3. Run the program:
   python password_generator.py
